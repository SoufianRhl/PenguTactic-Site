PenguTactic

A personal Teamfight Tactics analytics and machine-learning project for post-game analysis, performance tracking, and personalized coaching.

Post-game analysis

Designed to help review completed TFT matches and identify patterns in performance over time.

Riot API data

Uses official Riot Games API data to build structured, reproducible match analysis workflows.

Personalized ML

Explores machine-learning methods for private research into player-specific trends and coaching insights.

Purpose

PenguTactic is currently developed for personal/private use. The project focuses on historical match analysis and offline research. It is not intended to provide real-time, prescriptive in-game decision making.

Current status

V0 under active development. The current work covers Riot API integration, structured TFT match processing, local analytics, and baseline machine-learning experimentation.

Privacy & scope

The main application source code, datasets, models, credentials, and technical implementation remain private. This website is a public product overview only.
