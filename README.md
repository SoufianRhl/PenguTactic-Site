# PenguTactic

**PenguTactic** is a Teamfight Tactics post-game analytics and personalized coaching companion currently in prototype development and intended for future public release.

The product is designed to help players understand *how* a match developed, not only how it ended. The long-term V1 goal is to combine trustworthy match history, longitudinal player context, and permitted temporal game data into clear post-game timelines and personalized improvement insights.

## Public product direction

PenguTactic is focused on:

- post-game match review and personalized improvement;
- longitudinal analysis across matches, ranks, and patches;
- trustworthy structured TFT data with explicit provenance;
- temporal match reconstruction when permitted telemetry is available;
- privacy-conscious data handling and pseudonymized research outputs;
- a future public-facing coaching experience that remains explainable and evidence-based.

PenguTactic is **not** intended to provide real-time prescriptive decision-making, opponent scouting, hidden information, gameplay automation, or functionality outside Riot Games and platform compliance requirements.

## Current V1 status

The data foundation and continuous acquisition pipeline have been validated. Work is now centered on temporal match reconstruction and the post-game coaching layer required to complete V1.

The public website intentionally exposes only product-level status. Application source code, private datasets, credentials, models, raw identities, operational infrastructure, and internal development tooling are not published here.
